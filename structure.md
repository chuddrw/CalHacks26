> **What this file is for:** a map of every file in this folder, what it does, who owns it, and when it gets built. Read [plan.md](plan.md) first for the why. Every file also starts with its own note saying what it's for.

## Created later by tools (not in this skeleton)

| Path | Created by | Notes |
|---|---|---|
| `node_modules/` | `npm run setup` | Never commit it. |
| `.env` | You, from `.env.example` | One per laptop. Never commit it. |
| `shared/module_bindings/*.ts` | `npm run module:generate` | Generated; don't edit by hand. Committed, so nobody else needs the CLI. |
| `demo-app/.claude/settings.local.json` | `hooks/src/install.ts` | Per laptop, holds absolute paths, gitignored. |
| `demo-app/.mcp.json` | `hooks/src/install.ts` | Per laptop, holds absolute paths; install adds it to the clone's `.git/info/exclude`. |
| `demo-app/node_modules/` | `npm install` in demo-app | |
| `.git/cowork-*` files in each demo-app clone | the hooks | Small state files: `cowork-last-tree` and `cowork-listener.pid` stay; `cowork-index-<pid>` and `cowork-snapshot.lock` exist only while a snapshot runs. `demo-reset.ts` deletes them. |
| Temp worktrees | the watcher | `cowork-<pid>-*` under the OS temp folder; the watcher removes them when it exits, and on start removes any a killed watcher left behind. |
| `cowork-vitest-*.json` | the watcher | vitest's JSON report under the OS temp folder, deleted right after each check. |
| `<OS temp>/cowork-fixture/` | `npm run fixture -w watcher -- setup` | Test repos for the watcher. Delete whenever. |
