# Agent Cowork: file structure

> **What this file is for:** a map of every file in this folder, what it does, who owns it, and when it gets built. Read [plan.md](plan.md) first for the why. Every file also starts with its own note saying what it's for.

Times refer to the schedule in plan.md. Owners: A (hooks + MCP), B (watcher), C (module + demo app + diagnosis), D (UI + pitch).

## Created later by tools (not in this skeleton)

| Path | Created by | Notes |
|---|---|---|
| `node_modules/`, `package-lock.json` | `npm run setup` | Never commit `node_modules/`. Commit the lock file. |
| `.env` | You, from `.env.example` | One per laptop. Never commit it. |
| `shared/module_bindings/*.ts` | `npm run module:generate` | Generated; don't edit by hand. |
| `demo-app/.claude/settings.local.json` | `hooks/src/install.ts` | Per laptop, holds absolute paths, gitignored. |
| `demo-app/node_modules/` | `npm install` in demo-app | |
| `.git/cowork-*` files in each demo-app clone | the hooks | Small state files (last tree, listener PID). `demo-reset.ts` deletes them. |
| Temp worktrees | the watcher | Under the OS temp folder; the watcher removes them when it exits. |
