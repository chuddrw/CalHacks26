# Working with Orkio

This folder is the consumer app. The Orkio tool lives in `../orkio`.

Once connected, read team status and post your intent through the cowork MCP tools before changing shared behavior. Run `npm run typecheck` and `npm test` before reporting completion. Add behavior tests as the app grows; the initial scaffold has no test suite. Use `check_with_team` to check changes with teammates. Leave `wip/*` branches to Orkio's snapshot hooks.
